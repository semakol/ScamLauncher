# ScamLauncher

Лаунчер Minecraft-сборок: сборки лежат на Яндекс Диске, сам лаунчер обновляется из GitHub Releases.
Полный план — в [PLAN.md](PLAN.md), публикация сборок — в [docs/PUBLISHING.md](docs/PUBLISHING.md).

- Minecraft 1.16–1.21, загрузчики Fabric, Quilt, Forge, NeoForge — ставятся сами.
- Java скачивается автоматически (официальные сборки Mojang), ничего ставить не нужно.
- Вход по нику (оффлайн).
- Несколько сборок, у каждой своя папка, бета-версии по галочке.
- Свои клиентские моды, которые не пропадают при обновлениях.
- Докачка оборвавшихся загрузок; без интернета запускается уже скачанная сборка.

## Установка

Скачай файл под свою ОС из [последнего релиза](https://github.com/semakol/ScamLauncher/releases/latest):

| ОС | Файл |
|---|---|
| Windows | `ScamLauncher_x.y.z_x64-setup.exe` |
| macOS (M1 и новее) | `ScamLauncher_x.y.z_aarch64.dmg` |
| macOS (Intel) | `ScamLauncher_x.y.z_x64.dmg` |
| Linux | `ScamLauncher_x.y.z_amd64.AppImage` (обновляется сам; `.deb` — нет) |

Лаунчер не подписан сертификатом, поэтому при первом запуске:

- **Windows:** «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** перетащи в «Программы», запусти. Если macOS не даёт открыть — «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
  Если пишет, что приложение «повреждено»: `xattr -cr /Applications/ScamLauncher.app`.
- **Linux:** `chmod +x ScamLauncher_*.AppImage` и запусти.

Дальше лаунчер обновляется сам — предложит при запуске.

## Как лаунчер обращается с файлами

- **Моды сборки** проверяются перед каждым запуском: удалённые и изменённые скачиваются заново,
  лишние `.jar` в `mods/` удаляются.
- **Свои моды** клади в папку «Клиентские моды» (кнопка в лаунчере, это `mods-clients/` в папке игры).
  Они копируются в `mods/` при каждом запуске и не пропадают при обновлениях сборки.
  Если такой мод уже есть в сборке, лаунчер его не подключит и предупредит.
- **Настройки, управление, шейдеры, текстуры, конфиги** из сборки ставятся один раз и дальше твои.
  Если удалить папку целиком (например, `shaderpacks/`), при следующем запуске она вернётся.
  Вернуть к версии сборки — «Восстановить файлы…»; прежние файлы попадут в `.scam/backups/`.
- **Миры, скриншоты, свои ресурспаки и всё остальное** лаунчер не трогает.
- **«Проверить и починить»** заново проверяет все файлы игры и сборки и перекачивает испорченные.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Игра вылетает | Кнопка «Консоль» → «Копировать», пришли лог. Он же лежит в `.scam/logs/latest.log` в папке игры сборки («Папка игры»), прошлый запуск — `previous.log`. Отчёт Minecraft — «Отчёт о сбое». |
| Сломались моды или файлы | «Проверить и починить» в карточке сборки. |
| Испортил настройки или конфиги | «Восстановить файлы…», отметить нужное. Прежние файлы — в `.scam/backups/`. |
| Mac с M1+: старая версия (1.16) не запускается | Нужен Rosetta: `softwareupdate --install-rosetta` в Терминале. |
| Мало места на диске | «Настройки» → «Папка игры» → перенести на другой диск. |
| Нет интернета | Если сборка уже скачана — просто «Играть», запустится сохранённая версия. |
| Игра тормозит | «Настройки сборки» → память. Больше 75% памяти компьютера ставить не стоит. |

Где что лежит:

- **папка игры** (Java, Minecraft, сборки, миры) — «Настройки» → «Папка игры»;
  по умолчанию `%APPDATA%\ScamLauncher`, `~/Library/Application Support/ScamLauncher`, `~/.local/share/ScamLauncher`;
- **настройки лаунчера** — `settings.json` в папке приложения `ru.semakol.scamlauncher`
  (`%APPDATA%\ru.semakol.scamlauncher`, `~/Library/Application Support/ru.semakol.scamlauncher`, `~/.config/ru.semakol.scamlauncher`).

## Разработка

Нужны Rust (stable) и Node.js 22+.

```bash
cd app && npm install
npm run tauri dev
```

Проверить установку и запуск без интерфейса:

```bash
cargo run -p scam-mc --example launch -- 1.20.1 --loader fabric:0.16.14 --no-launch
```

Проверки как в CI:

```bash
cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace
```

## Выпуск версии

```bash
git tag v0.1.0 && git push origin v0.1.0
```

GitHub Actions соберёт установщики под Windows / macOS / Linux и `scam-pack` под все ОС,
подпишет обновления ключом из секретов `TAURI_SIGNING_PRIVATE_KEY` / `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`
и опубликует релиз. Версию в файлах вручную менять не нужно — она берётся из тега.

> Приватный ключ апдейтера хранится только локально (`~/.tauri/scamlauncher.key`) и в секретах GitHub.
> Если его потерять, установленные лаунчеры перестанут принимать обновления.

## Структура

```
crates/scam-core   общая логика: конфиг, формат сборок, Яндекс Диск, синхронизация
crates/scam-mc     установка и запуск Minecraft
crates/scam-pack   CLI публикации сборок
app/               лаунчер (Tauri + React)
scam.config.json   ссылка на Я.Диск, OAuth ClientID, репозиторий GitHub
```
