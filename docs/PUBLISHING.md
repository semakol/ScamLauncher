# Публикация сборок

Сборки публикует утилита `scam-pack`. Бинарники под все ОС лежат в каждом [релизе](https://github.com/semakol/ScamLauncher/releases/latest)
(`scam-pack-aarch64-apple-darwin`, `scam-pack-x86_64-pc-windows-msvc.exe` и т.д.). Из исходников:

```bash
cargo build --release -p scam-pack
```

Готовый бинарник будет в `target/release/scam-pack`.

## 1. Вход (один раз в год)

```bash
scam-pack login
```

Откроется страница Яндекса. Войди в аккаунт, **которому принадлежит папка сборок**, нажми «Разрешить»,
скопируй токен со страницы и вставь в консоль (можно вставить и адрес страницы целиком).
Утилита сама найдёт на диске папку, опубликованную по ссылке из `scam.config.json`.

Токен хранится в `~/Library/Application Support/scam-pack/token` (macOS), `%APPDATA%\scam-pack\token` (Windows)
или `~/.config/scam-pack/token` (Linux). Вместо файла можно задать переменную `SCAM_YANDEX_TOKEN`.
Токен живёт около года — когда истечёт, утилита попросит снова выполнить `login`.

## 2. Подготовка сборки

Собери сборку в любой папке — обычно это рабочий `.minecraft`/инстанс, в котором ты её проверял.
Рядом (или внутри) создай `pack.toml`:

```bash
scam-pack init --id techno --name "Техно" --minecraft 1.20.1 --loader forge --loader-version 47.4.0 --source ./minecraft
```

В `pack.toml` описаны:

- **`[pack]`** — id (менять нельзя), название, версия Minecraft, загрузчик, рекомендуемая память, папка `source`, иконка и фон, `exclude`.
- **`[[group]]`** — группы файлов. Файл попадает в **первую** подходящую группу.

| mode | Как ведёт себя у игрока |
|---|---|
| `sync` | Всегда как в сборке. Изменённые и удалённые файлы восстанавливаются перед каждым запуском. `prune` — где удалять лишнее (для модов: `["mods/*.jar"]`). |
| `once` | Ставится один раз, дальше это файлы игрока. Ставится заново, если игрок удалил корень группы целиком (папку `shaderpacks/`, файл `options.txt`), если ты увеличил `revision`, или по кнопке «Восстановить файлы сборки». |

Маски:

- `mods/*.jar` — `*` не переходит в подпапки;
- `config/**` — всё внутри на любую глубину;
- `re:^options(of|shaders)?\.txt$` — регулярное выражение по пути вида `config/x.toml`.
  В TOML пиши его в одинарных кавычках, чтобы не экранировать `\`.

Корни once-групп выводятся из масок (`shaderpacks/**` → `shaderpacks`; для регулярок — первая папка пути).
Задать вручную: `roots = ["config", "defaultconfigs"]`.

Файлы, не попавшие ни в одну группу, — ошибка публикации (чтобы личные файлы не утекли случайно).
Добавь их в группу или в `exclude`.

Всегда исключаются: `pack.toml`, иконка и фон, `.DS_Store`, `Thumbs.db`, `mods-clients/`, `.scam/`.

## 3. Проверка

```bash
scam-pack status
```

Покажет группы, файлы вне групп и разницу с опубликованной версией. Ничего не заливает, токен не нужен.

## 4. Публикация

```bash
scam-pack publish --version 1.3.0 -m "Create 0.5.1, новые шейдеры"
```

- Номер билда растёт сам. `--version` — видимая игрокам версия (без флага остаётся прошлая).
- Changelog: `-m "текст"` или `--changelog CHANGELOG.md`.
- Заливаются только файлы, которых ещё нет на диске. Одинаковые файлы в разных сборках хранятся один раз.
- Индекс обновляется последним: пока публикация идёт, игроки видят прошлую версию.
- Если ничего не изменилось, билд не выпускается (`--force`, чтобы всё равно).

## 5. Бета

```bash
scam-pack publish --beta --version 1.4.0-beta1 -m "Тестируем Create 6"
```

Бету видят игроки с галочкой «Бета-версии сборок» — если бета новее релиза. Когда всё проверено:

```bash
scam-pack promote techno
```

Бета становится релизом без перезаливки. Откат релиза на любой старый билд:

```bash
scam-pack promote techno --build 40
```

## 6. Прочее

```bash
scam-pack list
```
Сборки на диске, версии каналов.

```bash
scam-pack news add --title "Вайп 25 сентября" "Готовьтесь к новому миру"
```
Новость в лаунчере (`--pack techno` — только для одной сборки). `scam-pack news list`, `scam-pack news rm <id>`.

```bash
scam-pack gc --keep 10
```
Пробный прогон очистки: удалит все билды, кроме 10 последних (и текущих релиза с бетой), и файлы, на которые больше
никто не ссылается. С `--yes` — удаляет по-настоящему (в корзину Диска; `--permanently` — мимо корзины).

## Что лежит на Диске

```
ScamLauncher/
├─ index.json                   сборки и текущие билды каналов (релиз/бета)
├─ news.json
├─ packs/<id>/builds/<N>.json   манифест билда (не меняется после публикации)
└─ objects/<ab>/<sha1>          файлы, имя = хэш
```

Руками в этой папке ничего не меняй — только через `scam-pack`.
